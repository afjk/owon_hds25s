# OWON Scope — Tauri版 0.4.1

HDS25S用のMacデスクトップアプリ。Tauri 2 + React/TypeScript + Rust。
公式PCソフトの機能を順に再実装する土台であり、**公式ソフトとの完全互換版ではありません**。
公開リポジトリはソースコードのみです。ビルド済みアプリ、ローカルのバックアップ
（`snapshots/`）、実機の取得・検証記録や第三者配布物（`research/`・`tmp/`）は含みません。
以下の過去の実機確認は開発時の記録であり、現在の接続状態を示すものではありません。
テスト用JSONは合成データです。

0.4.1にはAuto用の全設定読取りと確認・変更一覧UIを追加しました。ただし、復元事前テストでCH2感度100→200 V/divの不一致を検出したため、**Autoの実行はUI・Rustの両方で無効**です。Autoコマンド自体はまだ本実機に送信していません。2026-10-04、本体操作でCH2を100 V/divへ戻していただいた後、読取専用の確認で入力・水平・取得14項目、トリガ設定5項目、GEN設定7項目が元の記録と一致しました。GEN OUTはOFFです。記録：`research/hardware/20261004-after-manual-scale-restore-read.json`。遠隔での感度復元方法は未解決のため、Auto実行はまだ有効にしません。

トリガーレベルには初期OFFの「丸め対策（実験的）」を追加しました。送信値に符号付き100 µVを加え、読戻しは補正前の指定値と比較します。160 mV維持は確認できましたが、320 mV指定は160 mVのままで不一致でした。全範囲の解決ではありません。負値や異なる感度は未検証です。時間・電圧の校正は未実装のままです。

## 起動

プロジェクト直下の **OWON Scope.command** をダブルクリックします。
ビルド済みの `src-tauri/target/release/bundle/macos/OWON Scope.app` を直接開くこともできます。
Release版がない場合、ランチャーはDebug版を開きます。
Node・Rust・Python・Homebrewはビルド済みアプリの通常起動には不要です。
USBライブラリは静的リンクし、Mac版の依存ライブラリがOS標準だけであることを確認しました。
macOS 11以降、このMacのApple Silicon向けビルドです。Intel Macは別ビルドが必要です。
Macのアプリバンドルはローカル開発用のad-hoc署名です。Developer ID署名／Apple公証は未対応で、一般配布向けの署名ではありません。

1. 本体をオシロスコープモードにして、System 2/2 のUSBをHIDにします。
2. 他のOWON接続アプリを切断し、USBで接続します。
3. 「再検索」で実機を選び「接続」を押します。起動時の検索は自動ですが、接続は手動です。
4. CH1／CH2へ測定対象を接続します。センサー種別・用途は固定しません。

USBが見つからない場合は、ケーブル、本体モード、他アプリ、実行権限を確認します。
Codexの制限付きプロセスではUSB一覧が空になる場合があります。
通常のFinder/ターミナルからの起動でも確認してください。
複数台の接続では選択したbus/addressだけを開きます。
抜き差しによりアドレスが変わる場合は「再検索」してください。

## 操作

- **表示停止／再開**：Macの連続照会を止めます。本体のRUN/STOPを変更しません。
- **1回取得**：本体状態と設定情報を更新し、現在の波形を1回読みます。表示停止中にも使えます。
- **照会の最小間隔**：17/33/100/500/1000 ms。USB応答が遅ければその速度に制限されます。
- **CH表示、反転、色、上下分割、点／線、背景、格子**：PC表示だけを変更します。
- **移動／拡大**：ドラッグでX/Y移動、ホイールでX拡大、Shift+ホイールでY拡大。「表示リセット」で全体へ戻します。
- **カーソル**：重ね合わせの波形表示でX/Y/両方を選択。ドラッグまたは数値入力で移動します。Shift+ドラッグは波形移動です。
- **XY**：CH1をX、CH2をYにします。両CHのデータが必要です。
- **演算**：和・差・積・除算・二乗。演算結果を紫色で重ねます。ゼロ除算の位置は線を途切れさせます。
- **FFT**：Rectangular/Hann/Hamming/Blackman。平均値を除去し、先頭の2の累乗長で計算します。横軸cycles/byte、縦軸raw RMSまたはdB re 1 raw RMSです。
- **データ表**：両CH／CH1／CH2を選択。表示は500行ごとのページ切替で、表出力には選択したCHの全行を含めます。
- **JSON保存**：押した時点の元データとヘッダーを保存します。ライブとSTOP確認済みの区別を保存内容にも残します。
- **本体STOPを確認して取得・保存**：本体で両CHをONにしてRUN/STOPで停止してから押します。取得前後のSTOP・ヘッダー一致・両CHの長さを検証します。成功／失敗のどちらでもMacの表示を停止します。
- **開く／履歴**：USBを切断してからJSONを開きます。旧Python版のSTOP保存JSONも読めます。最近の10ファイルを記憶します。
- **再生**：「開く」で複数JSON（最大100件）を選択、または「再生フォルダー」で記録セッション内のJSON（最大10000件）を開きます。順／逆方向、間隔、前後送り、スライダーに対応。フォルダーはファイル名順、複数選択は選択順で、保存時刻からの再構成はしません。
- **自動保存**：フォルダーと間隔（500〜60000 ms）を選んで開始。保存先に新しい `owon-…` セッションフォルダーを作り、`wave-000001.json` から連番保存します。Rust側の専用スレッドで保存するため、アプリが背面／最小化中も動作します。表示停止・未更新フレームはスキップし、無制限にキューを溜めません。USBエラーや保存失敗では記録を停止して通知します。
- **画像保存**：PNG／BMP／GIFから選択。PCで描いた波形画像です。本体の画面キャプチャではありません。
- **表出力**：CSV／TXT／XLSから選択。受信バイト位置とsigned int8値の未加工データで、電圧データではありません。XLSは実際のBIFF8/OLE形式で、数値セルと取得情報シートを保存します（拡張子だけの変更ではありません）。XLSはヘッダー込み65536行が上限です。
- **印刷**：押した時点の波形画像を固定してプレビュー。A4縦／横、上下左右0〜40 mmの余白を指定し、macOSの印刷ダイアログから印刷／PDF保存します。Windows側は未検証です。
- **本体操作**：CH1／CH2の表示・結合・プローブ倍率・感度・オフセット、水平時間軸・位置、取得方式・メモリ長を選び「本体へ適用・読戻し」。これはPC表示だけでなく実機設定を書き換えます。変更前→指定値の送信→変更後の照会を直列実行し、一致／不一致を表示します。機種非対応や範囲外の値は本体が拒否する場合があります。不一致時に自動で別の値を書き込むことはありません。
- **本体の測定値を取得**：CH1／CH2の周波数・周期・Vpp・最大・最小・平均を照会します。表示には取得時刻を残し、自動更新はしません。各項目は逐次照会で、表示中の波形と同時刻の測定とは限りません。
- **トリガー**：専用パネルの「トリガー現在値を読取り」を押し、信号源CH1／CH2、トリガ結合DC／AC、エッジRISE／FALL、モードAUTO／NORMAL／SINGLE、レベルを1項目ずつ「トリガーへ適用・読戻し」で変更します。現在の対応機種／FWはHDS25S V12.1.0。直前の5項目が変わっていれば書込みを中止します。書込みは1回だけで、読戻しは2回連続で設定が一致するまで最大4回確認します。源・結合の切替でレベルが連動した場合は、その変化も表示します。レベルはV／mV／uV入力、アプリ上限±100 V。本体の量子化で指定値と異なる場合は再読取りを求め、自動補正しません。SINGLEの適用には確認チェックが必要です。再待受は本体のRUN/STOPで行います。Macの「1回取得」や「表示再開」は本体の再待受ではありません。GEN OUTを用いた設定切替・Single停止を実機確認済みです。
- **GEN OUT**：右側のパネルで現在の波形種・周波数・周期・振幅・オフセット・出力状態・負荷を読めます。接続時は読取りだけを行い、設定や出力ON/OFFは自動適用しません。接続先を確認し「出力ON…」の確認チェックと確認ボタンを押した後、項目と値／単位を選び「GEN OUTへ適用・読戻し」で1項目ずつ変更します。設定変更は出力ON中のみ許可します。OFFは独立ボタンです。本体手動操作で前回値と異なれば、書込みせず再読取りを求めます。ただしOFFは他の設定が変わっていても操作できます。
- **言語／設定**：上部で日本語／英語を切替。ヘルプに操作と制限を表示します。表示色・CH表示・反転・格子・FFT窓などを記憶し、本体設定は起動時に自動適用しません。一部の通信エラー／通知は日本語です。
- **ショートカット**：Space＝表示停止／再開、Cmd/Ctrl+S＝JSON保存、Cmd/Ctrl+O＝開く、Cmd/Ctrl+P＝印刷プレビュー、R＝表示リセット。

GEN OUTの操作対象は現在HDS25Sのみです。SINE／SQUARE／RAMP／PULSEに対応し、振幅は0.02〜5 Vpp、アプリ安全制限は `|オフセット| + 振幅/2 ≤ 2.5 V`。負荷がINFの場合に限り設定を変更し、負荷切替・任意波形・パルス幅・デューティは未対応です。接続先回路の定格を確認してください。周波数の1 kHz→2 kHz変更と出力ON/OFFは実機確認済みですが、その他の全設定範囲は実機検証未完了です。OFF中のSINE指定で本体が自動ONになったため、OFF中の設定書込みをUI・Rustの両方で禁止しています。

保存は既存ファイルを**上書きしません**。新しい名前を指定してください。
JSON読込／保存は最大5 MiB。画像の入力PNGは最大5 MiB／4096×4096、デコード上限64 MiB、出力は最大32 MiB。表／XLS出力も最大32 MiBです。
自動保存には保存先の空き容量が必要です。ディスク容量による自動ローテーションは未実装です。
Macのスリープ中はネイティブ保存も停止します。保存間隔はベストエフォートで、全収録の連続記録やハードウェア時刻同期ではありません。
ファイル再生はWebViewのタイマーを使い、背面時に遅くなる場合があります。
保存に失敗した場合、作成途中のファイルが残ることがあります。
ライブJSONは旧Python版の「停止波形を開く」では開けません。互換性は旧STOP JSON→Tauri版の方向で確認しました。

## 測定上の制限

600バイトの意味（ペア／包絡情報等）と時間・電圧変換はまだ未検証です。
表示は**受信バイト位置とsigned int8値**であり、ADCサンプル位置・秒・ボルトではありません。
生の値のpeak-to-peak、平均、RMS、演算、FFTは診断用です。
ヘッダーのADC rateの逆数を画面波形の点間隔として扱いません。
カーソルの差分はΔX(byte)/ΔY(raw)であり、まだΔt/ΔV計測ではありません。
反転・演算・表示色は元データを書き換えず、JSON/CSVは未加工データを保持します。
本体の自動測定値だけは本体が返したHz／s／Vとして別枠に表示します。これはPC波形軸の校正完了を意味しません。

ライブのCH1/CH2は順番に照会します。同一収録を示すIDはなく、CH間の収録一致は未検証です。
STOP保存も前後の状態・設定一致を確認する方式で、同一収録IDによる証明ではありません。
本体情報はライブで約1秒キャッシュするため、設定変更の反映は遅れる場合があります。
アプリからの本体設定変更後はキャッシュを破棄して取得し直します。
「表示更新/秒」はPCへの適用数であり、本体の独立した新規収録数・ADC rate・ディスプレイの物理Hzとは異なります。

通信応答が不完全／不正になった場合は取得を終了し、元の応答を途中から再解釈しません。
USBを抜き差しし、再検索・再接続してください。アプリからのUSBリセットやドライバー強制解除はしません。

## 実装構成

[API仕様書](docs/device-api.md)に、登録済み26 API（Auto実行は無効）の引数・戻り値・エラー・本体への影響と、実機確認範囲をまとめています。

- `crates/owon-core`：USB、許可リスト付きSCPI照会／設定、フレーミング、STOP整合性検証、保存形式。GUIから独立。
- `src-tauri/src/worker.rs`：USBの生成から解放まで単一スレッドで所有。最新フレームだけを保持するメールボックス。
- `src-tauri/src/main.rs`：検証付きの接続／取得／保存／出力操作。USB操作は直列実行する。
- `src-tauri/src/recording.rs`：フロントエンドのタイマーに依存しない連続JSON保存。
- `src-tauri/src/export.rs`：上書き防止の表／画像出力。画像形式は実データを変換する。
- `src/App.tsx`：操作・保存・再生。最新データの取得リクエストは1件ずつ実行し、古い表示をキューにしない。
- `src/ScopeCanvas.tsx`：Canvas描画。アニメーションクロックと背面時のタイマーを併用し、波形以外の情報は最大4回/秒更新。
- `src/model.ts`：表示用の純粋な統計・演算・FFT。
- `src/DeviceControls.tsx`：本体の設定と自動測定値。自由入力のSCPIコンソールではない。
- `src/GeneratorControls.tsx`／`crates/owon-core/src/generator.rs`：GEN OUTの現在値、単位付き入力、1項目ずつの適用、出力ON確認、設定保持検査。
- `src/TriggerControls.tsx`／`crates/owon-core/src/trigger.rs`：トリガー5項目の現在値・本体状態表示、競合検出、Single確認、1項目ずつの設定保持検査。接続時や保存ファイルを開いた時に自動適用しません。
- `src/PrintPreview.tsx`／`src/xls.ts`：固定画像の印刷、SheetJSによるBIFF8表出力。

Tauri Channelsを試した初版は実機の画面転送に問題があり、現在は最新メールボックスをIPCで取り出す方式を採用しています。
Channels側の根本原因は未確定です。将来の最適化で再比較できます。
将来のAI操作は、画面の操作と同じ明示的な操作インターフェースを経由させる設計です。
自由生成したSCPI文字列をそのまま実行する経路はありません。

## 開発・検証

Rust 1.90以上、Node、macOSのXcode Command Line Toolsが必要です。
このMacではRust 1.91.1、Node 22.22.2、Tauri 2.12.1、React 19.3.0でビルドしました。
`package-lock.json` と各 `Cargo.lock` を保存しています。

```sh
cd tauri-app
npm ci
npm run tauri -- dev
npm run tauri -- build
npm test
cargo test --manifest-path crates/owon-core/Cargo.toml
cargo test --manifest-path src-tauri/Cargo.toml --release
```

ディスク容量が少ない場合は、ReleaseとDebugの依存ビルドが数GBになることに注意してください。
この作業環境のようにホームのキャッシュが書込み禁止の場合：

```sh
npm_config_cache=/private/tmp/owon-tauri-npm npm ci
CARGO_HOME=/private/tmp/owon-tauri-cargo npm run tauri -- build
```

USB診断はアプリを切断してから実行します。通常の一覧、`--read`、`--measurements`は読取専用です。
**`--settings`だけはCH1の結合を現在と同じ値で書き戻して検証します。** 実機操作中に実行しないでください。

```sh
cargo run --manifest-path crates/owon-core/Cargo.toml --bin probe
cargo run --manifest-path crates/owon-core/Cargo.toml --bin probe -- --read
cargo run --manifest-path crates/owon-core/Cargo.toml --bin probe -- --measurements
# 読戻し・同値書込みの確認（上の注意を参照）
cargo run --manifest-path crates/owon-core/Cargo.toml --bin probe -- --settings
```

初回のRust診断でHDS25S／V12.1.0から両CH 600バイトを取得。
40回のライブ取得は平均34.12 ms、29.31回/秒。GUIでも約30回/秒、照会約32〜33 msを確認しました。
接続／連続取得中にタイムアウトやフレーミング不正も観測しています。
その前後にユーザーの実機／接続操作があったとの申告があるため、原因をソフトだけに断定していません。
長時間安定性、校正、計測精度の保証ではありません。

0.2の実機確認では約29〜30回/秒の表示、本体の測定12項目、CH1結合DC→DCの読戻し一致を確認。
